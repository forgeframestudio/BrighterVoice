# BrighterVoice v0.1

Free proof-of-concept AAC communication interface.

## What works
- Large mobile-first communication buttons
- Tap to build a message
- Touch, hold, slide across choices, then release to select
- Device/browser text-to-speech
- Clear message
- Caregiver-added custom words/phrases saved locally
- Responsive layout for phones and tablets

## Important
This is an early prototype, not a clinically validated AAC medical product. It should be tested with AAC users, families, SLPs, OTs, educators, and accessibility specialists before being relied upon as a person's sole communication method.

## iPhone
The project needs to be hosted over HTTPS to behave like a normal web app on an iPhone. Once hosted, open it in Safari and use Share > Add to Home Screen.
